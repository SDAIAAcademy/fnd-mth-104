Block A · the null model

A null model says how the data would look if nothing were going on

  • Groups assigned at random, no effect: the labels could have been any relabelling
  • Two columns with no relation: any pairing is as likely as the observed one
  • A permutation test builds the null by shuffling, and counts

The question it answers

If the labels did not matter, how often would a shuffle give a difference at least as large as ours?

Contrast with week 5: the bootstrap resamples each group to estimate; the permutation test pools and shuffles to build "no effect".

Three against three: twenty splits, two as extreme as the data

Observed difference: 9 − 4.33 = 4.67

p = 2 / 20 = 0.10
two-sided, from every split

Block A · at scale

With many rows, shuffle a few thousand times instead of listing every split

obs = x.mean() - y.mean()
pooled = np.concatenate([x, y])
k, count = len(x), 0
for _ in range(R):
    p = rng.permutation(pooled)
    d = p[:k].mean() - p[k:].mean()
    count += abs(d) >= abs(obs)
p_value = (count + 1) / (R + 1)

The +1 counts the observed labelling as one of the possible ones: the p-value is never zero, and its floor is 1 / (R + 1). Report R. SciPy's permutation_test does the same; its two-sided p-value doubles the smaller one-sided p-value, which can differ from counting |difference| on a lopsided null. The lab compares the two.

Block B · misreadings

What a p-value does not mean

Misreading of p = 0.03Correction
"A 3% chance that there is no effect"p assumes no effect; it is not the probability of that assumption
"A 97% chance that the effect is real"The same reversal, stated the other way
"The effect is large"p mixes size and sample size; report the effect size
"p = 0.06, so there is no effect"Not enough evidence at this size is not evidence of none

These four plus the interval misreadings of week 4 make up most of the LO2 ten-statement sheet. Ask participants to find one in a report they have read this year. Sources: the American Statistical Association's statement on statistical significance and p-values (2016), principles 2 (a p-value does not measure the probability that the hypothesis is true) and 5 (it does not measure the size of an effect).

Checkpoint

Correct the sentence

A report says: "p = 0.01, so there is only a 1% chance that the new schedule has no effect." Which correction is right?

"There is a 99% chance the schedule works."
"The schedule improves the outcome by 1%."
"If the schedule had no effect, a difference at least this large would arise in about 1% of relabellings."
"The result is significant at the 5% level, so the effect is certain."
Why. A p-value is computed assuming no effect; it cannot be the probability of that assumption.

Block C · effect size

Report how big the effect is, with an interval, then the test

Difference

In the outcome's own units: minutes, riyals, visits.

Ratio

"48% more": useful when the level differs between settings.

Correlation

For two numeric columns: from −1 to 1, with its interval.

Practical significance: compare the interval with the smallest effect that would change a decision.

The interval for each comes from the week 5 bootstrap. With thousands of rows a tiny, useless effect gets a tiny p-value; the effect size and its interval show that it is tiny.

Block C · the reading

A plain-language reading states the size, the uncertainty and what chance can explain

Template

"[Group A] [did more/less] [outcome] than [group B]: [difference] ([interval]). Shuffling the labels gave a gap this large in [p as a share] of [R] shuffles. [What this does and does not show.]"

Avoid: "proves", "significant" on its own, "the probability that the null is true", and causal words for observational data.

The brackets are the parts of the sentence participants fill; the lab's step 7 writes one reading per question. For Engel's data the honest verb is "went with", not "caused".
